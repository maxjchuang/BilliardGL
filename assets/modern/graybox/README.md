# Focused Practice Hall M1 Graybox

This package is an original, procedurally generated glTF 2.0 validation asset. It contains no competitor content, external model, texture, image, or binary sidecar.

`focused_practice_hall_m1_alignment_v1.json` binds the generated bytes to the approved M1/M2 compatibility geometry: `chinese_pool_interactive_120hz_v5`, `legacy_v1`, `legacy_opening_band`, 86.483976 cm surface, 1.4R nose, mouth-only pockets, 0.05 cm marker tolerance and 0.10 cm visual-solid clearance. Capture presentation remains simulation-driven.

It is intentionally a graybox, not a production high mesh. The pocket funnels are recessed, visual-only proxies. Production jaw, throat and capture geometry remains blocked by `docs/art/table-visual-physics-alignment-contract.md` section 10.

Contents represented in the generated `.gltf`:

- compatible play surface at `0.86483976 m`;
- six visible cushion segments;
- six mouth-only visual pocket proxies;
- one cue proxy with its origin at the tip contact face;
- one shared sphere mesh and one preview instance;
- one rectangular lamp housing and diffuser;
- a simple 10×10×4 m room shell;
- play-surface, four rail-nose and eighteen pocket mouth/endpoint sockets.

Regenerate and validate:

```sh
python3 scripts/generate_m1_graybox_gltf.py \
  --output assets/modern/graybox/focused_practice_hall_m1_graybox.gltf \
  --alignment-output assets/modern/graybox/focused_practice_hall_m1_alignment_v1.json
python3 scripts/validate_m1_graybox_gltf.py \
  assets/modern/graybox/focused_practice_hall_m1_graybox.gltf
python3 -m unittest tests.visual.test_m1_graybox_gltf
```

The committed output must be byte-identical to a fresh generation.
