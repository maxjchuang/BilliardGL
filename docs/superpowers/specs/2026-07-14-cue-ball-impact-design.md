# 第三阶段主题 2：球杆—母球接触设计

日期：2026-07-14

## 1. 目标

把用户力度直接映射为母球线速度的规则替换为可测量的球杆接触，使击点产生高杆、低杆、侧旋及明确的 stick、slip 和 miscue 状态。

## 2. 输入与参数

物理输入包含球杆速度、方向、质量及有效质量，杆头半径与材料，水平/垂直击点偏移，杆头摩擦和母球碰撞前状态。游戏 `shotPower` 通过独立、版本化、单调的 `ShotPowerMapping` 转换为球杆速度，不混入碰撞公式。

## 3. 接触响应

模型计算法向和切向相对速度、冲量、母球接触后线速度和角速度，以及接触 regime。切向冲量满足：

```text
|J_t| <= mu_tip * J_n
```

维持粘着所需冲量超过摩擦上限时进入滑动；偏移越过可靠接触边界时判为 miscue，不能无限增加旋转。传入球的能量不得超过球杆对接触所做的功。

## 4. 2.5D 边界

水平球杆及平面内线速度和完整三维角速度进入数值验收。仰角保留在 schema 和 telemetry；需要跳球、扎杆或显著竖直冲量时明确返回 unsupported/limitation，不静默投影。

## 5. Telemetry 与验证

记录球杆接触前后速度、接触点、法向/切向相对速度、法向/切向冲量、regime 变化、母球线速度/角速度和能量效率。

Cross 2023 全文和实验点未合法取得前，只实现接口、解析力学及硬约束，不声明通过该来源。解析测试覆盖中心击球无额外旋转、偏移符号、左右镜像、摩擦锥、能量上限和滑杆边界。取得完整数据后，中心和中等偏移作为 calibration，极限旋转和滑杆边界保留为验证集。

## 6. 非目标与完成标准

本主题不模拟球杆有限元振动、跳球、扎杆或挥杆动画。完成时，自动化和普通玩家输入都通过同一球杆接触模型，Cross 的 contact telemetry limitation 被解除；缺失实验数据的 limitation 继续保留。
