# 第三阶段主题 1：单球台面运动与旋转设计

日期：2026-07-14

## 1. 目标

替换统一恒减速度和仅用于画面的旋转，实现球心线速度、三维角速度、滑动、纯滚动和停止之间的真实耦合。

## 2. 状态与模型

球与台呢接触点的切向相对速度为：

```text
u_contact = v_center + omega × r_contact
```

`|u_contact|` 高于阈值时为滑动；接触点相对速度降至零后进入纯滚动；线动和转动能量均低于数值停止阈值后进入静止。侧旋分量独立保留，不得伪装成普通滚动摩擦。

滑动阶段采用库仑摩擦。摩擦力同时改变线速度和角速度，球的默认转动惯量为实心球 `I = 2/5 mr²`。纯滚动阶段使用独立滚动阻力并维持运动学滚动约束。

## 3. 数值积分

每个 tick 检测滑动到滚动和滚动到停止事件。如果事件发生在 tick 内，则按精确事件时间分段积分。即将停止时积分到停止点，不允许速度或角速度反向。不得通过直接截断角速度制造纯滚动。

首批参数包括：

- `sliding_friction_coefficient`；
- `rolling_resistance_acceleration_cm_s2`；
- 有证据时启用的 `torsional_spin_decay`；
- `slip_speed_epsilon_cm_s`；
- `stop_energy_threshold`；
- 球质量、半径和惯量模型。

材料参数可由 calibration 拟合；数值阈值只能由精度、稳定性和时间步收敛确定。

## 4. Telemetry

逐 tick 记录接触点滑动速度、运动状态、摩擦力、摩擦力矩、线动能、转动动能和状态转换时间。碰撞后的球必须能暴露稳定纯滚动窗口，供实验指定阶段采样。

## 5. 验证

Calibration 使用 Mathavan 2009 滚动减速度组和预注册 Table I calibration shots。验证使用滑动减速度、剩余 Table I shots 及高低速度边界。解析测试覆盖无侧旋滑动解、纯滚动约束、正逆旋和镜像场景。

硬门槛：

- 摩擦不增加总动能；
- 不产生反向减速、NaN 或无限状态；
- 时间步缩小时转换时间、距离和停止状态收敛；
- 镜像、旋转和球编号不改变等价结果；
- 直接场景和完整游戏产生相同权威轨迹。

## 6. 非目标与完成标准

本主题不处理球杆生成旋转、碰撞旋转传递、库边摩擦或多接触。完成时，滚动/滑动 mismatch 由新模型重新判定，Mathavan Table I 的碰撞后纯滚动阶段可执行；是否通过仍由实验区间决定。
