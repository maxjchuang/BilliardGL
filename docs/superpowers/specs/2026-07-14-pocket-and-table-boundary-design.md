# 第三阶段主题 5：袋口与台面边界设计

日期：2026-07-14

## 1. 目标

替换矩形开口带与固定深度判定，建立与球半径、袋口、库鼻接触和扫掠轨迹一致的进袋与拒球模型。

## 2. 权威几何

物理几何独立于渲染 mesh，包含比赛区域、球半径、角袋/中袋宽度、库鼻位置与曲率、袋口朝向、喉部和捕获区域。渲染层可以读取物理几何，但不能成为碰撞真值。

每个袋口由直线库边、左右库鼻和喉部形成连续边界。球心可达区域使用球半径进行几何偏置；角袋和中袋使用不同参数。直线部分复用主题 4，库鼻以局部曲面法线调用相同接触接口。

## 3. 进袋状态机

袋口交互状态为 `approaching`、`jaw_contact`、`throat_crossed`、`captured` 和 `rejected`。只有进入无法返回台面的 `captured` 区域才发送 `ball_pocketed`。捕获后停止 2.5D 台面物理，完整下落只属于表现层。

## 4. 连续检测

对 tick 内的扫掠轨迹求最早直库、库鼻或喉部事件。高速球不得穿过库鼻；事件优先级稳定且可重放。同一时刻双库鼻接触由主题 6 的 contact island 求解。

## 5. 验证

角袋和中袋按横向偏移、入射角、速度、正逆旋、侧旋、擦边深度和左右库鼻接触形成自动扫描矩阵。

硬门槛：镜像一致、帧率与球编号无关、无穿越实体库鼻、无重复进袋、捕获后不返回、时间分辨率收敛，以及球直径大于有效通道时不能通过。

袋口真实轨迹实验不足时，只用 WPA/Chinese Pool 几何、解析可达性和分类连续性验收，并保持 C 级证据。视觉观感不能升级真实性结论。

## 6. 非目标与完成标准

本主题不模拟袋内三维下落、球道、回球机构或软材料形变，也不包含犯规和胜负规则。完成时游戏规则只消费统一物理事件，袋口边界可以自动扫描、重放和审计。
