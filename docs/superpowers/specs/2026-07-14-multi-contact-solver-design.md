# 第三阶段主题 6：求解器与多接触设计

日期：2026-07-14

## 1. 目标

消除固定大步长和逐球遍历导致的高速穿透、碰撞顺序依赖、重复冲量和球堆不稳定，使前面所有单接触模型能够组合运行。

## 2. 时间与连续碰撞

渲染使用可变帧率，权威物理使用固定 tick；时间累积器每帧执行零个或多个完整物理 tick。机器负载不得改变物理步长。

每个 tick：

1. 建立候选接触；
2. 求球球、直库、库鼻等最早碰撞时间；
3. 推进到最早事件；
4. 建立时间容差内的 contact island；
5. 联合求解；
6. 推进剩余时间并重复。

主题 1 的台面作用在每个实际时间段积分，不在 tick 末统一扣减。

## 3. Contact island

Island 联合处理法向约束、切向摩擦、恢复、旋转耦合、累积冲量和穿透位置修正。单接触本构由主题 2–5 提供，求解器不复制材料公式。

接触使用稳定规范化键，迭代次数和阈值由 `SolverSettings` 固定。排序只保证确定性；真正的顺序无关还必须通过球编号置换、接触生成顺序打乱和对称场景测试。

## 4. 穿透与安全上限

位置投影与速度冲量分离，投影不直接增加能量。Telemetry 记录最大穿透、接触数、迭代数和残余误差。

每个 tick 固定最大事件数、island 大小、求解迭代、穿透、有限速度和角速度。达到上限保存完整状态并返回 `NUMERICAL_FAILURE`，不得丢弃接触或静默瞬移后继续。

## 5. 验证

场景包括高速跨步碰撞、三球直线传递、牛顿摆、对称同时接触、双库鼻、贴库、球堆、完整开球和固定种子随机击球。

扰动包括球编号置换、候选接触顺序、渲染帧率、执行负载、物理 tick 和重复种子。硬门槛为无漏碰、重复冲量、NaN、能量爆炸和超限穿透；同平台确定性复现；对称场景无偏置；混沌场景统计量处于预注册区间。

## 6. 非目标与完成标准

本主题不建设通用三维引擎、有限元或 GPU 求解器。完成时开球、密集球堆和连续多库由统一事件驱动 stepper 稳定运行，任何失败都能单场景重放。
