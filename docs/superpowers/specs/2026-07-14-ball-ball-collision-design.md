# 第三阶段主题 3：球—球碰撞设计

日期：2026-07-14

## 1. 目标

替换等质量、完全弹性、只交换法向速度的实现，使质量、法向恢复、接触摩擦和旋转共同决定碰撞结果。

## 2. Contact 输入

接触记录包含两球标识、接触点和法线、碰撞前相对线速度、接触点切向速度、质量、半径、惯量、材料对、穿透和首次接触时间。只有法向相对速度正在接近时才能施加速度冲量。

## 3. 冲量模型

法向冲量由有效质量和恢复系数决定；切向冲量根据接触点相对速度求解并满足 `|J_t| <= mu_ball * J_n`。冲量同时更新两球线速度和三维角速度。恢复与摩擦保持独立参数，位置修正与速度冲量分离。

`PhysicsProfile` 允许场景覆盖球直径、质量、惯量、表面材料、恢复和摩擦，使 Domenech 的 billiard、steel、brass 和 rubber 系列按真实器材运行。Chinese Pool 默认参数不被实验 profile 改写。

初始候选采用有理论支持的常数恢复。速度相关模型只有在 calibration 和独立物理证据共同支持时才形成新公式版本，不根据验证误差临时增加自由参数。

## 4. 碰撞后阶段

瞬时接触只产生碰撞后状态，随后交给主题 1 处理台面滑动和纯滚动。Analyzer 按实验定义分别采样 immediate post-impact、post-transition pure rolling 和最终停止阶段，禁止用首个碰撞后 frame 替代纯滚动测量。

## 5. 验证

Calibration 使用 Domenech 预注册低角度材料系列及 Mathavan 2009 calibration Table I shots。验证使用中高角度、post-transition、剩余 Table I 和极薄碰场景。

硬门槛包括线动量约束、非增能、法向分离、不重复冲量、编号置换和镜像等价、时间步收敛，以及碰撞后稳定进入主题 1 定义的运动状态。

## 6. 非目标与完成标准

本主题不处理有限元形变、三球同时接触或库边参数。完成时 Domenech 的场景几何/material limitation 转为可执行点，Mathavan Table I 完成从碰撞到纯滚动的端到端验证；结果仍按适用性和实验区间分类。
