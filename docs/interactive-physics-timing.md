# 交互物理与渲染时间规范

## 时间域

- 桌面交互模式使用 `interactiveChinesePoolPhysicsProfile()`，固定物理频率为 120 Hz。
- 显示刷新由窗口系统垂直同步调度，不得使用固定 16 ms 定时器，也不得作为物理
  时间来源。60、120、144 Hz 显示器可按各自刷新节奏提交画面。
- 公开实验、自动化场景和证据回放继续使用场景中显式声明的
  `time_step_seconds`；不得因交互模式调整而静默改写。
- 自动化 `step(ticks)` 始终表示精确执行指定数量的场景物理 tick。
- 交互模式的接触恢复上限为 `2.75 cm`（仍小于 `2.8575 cm` 球半径），用于恢复
  真实冲球速度下同一 tick 内连续碰撞产生的库边重叠；证据回放配置仍保持原有
  `0.5 cm` 上限。

交互 profile 使用独立 profile ID。除求解器时间步外，它还采用仅面向桌面体验的
台呢与力度标定；公开实验、自动化场景和证据回放的冻结 profile 不受影响，使
运行日志和 Trace 能够明确区分交互运行与证据回放。

## 击球速度与台呢衰减

- 滑动阶段使用 `mu = 0.20`，球从无旋的初始滑动自然过渡为纯滚动，不再用同一个
  常量减速度贯穿全程。
- 滚动阶段使用 `12.5 cm/s^2` 的阻力减速度，对应 Mathavan、Jackson 与 Parkin
  使用高速摄影测得的 `0.124--0.126 m/s^2` 范围。
- 交互模式以 `12 rad/s^2` 衰减绕竖直轴的侧旋，并在归零前继续推进物理时间，
  避免球停止平移后纹理仍无限原地旋转。该值属于体验标定，不作为公开实验结论。
- 60 档及以下保持每单位 `1.675 cm/s` 的线性杆速映射。60 档产生
  `75 cm/s` 球速，无碰撞停距约 `121.8 cm`，对应开球位至球堆首球的可行
  净行程。
- 60 档以上使用一阶连续的二次曲线；100 档约产生 `2.1 m/s` 球速，150 档
  约 `5.8 m/s`，200 档达到 `10.0 m/s`。最大值位于公开职业开球测得的
  `9.8--11.6 m/s` 范围内。
- 100 档以上把垂直击点从球心逐步提高，200 档达到 `0.40R`，使最大力度母球
  以接近纯滚动的前旋离杆。它是当前 2.5D 引擎对真实强力开球短暂腾空/低台呢
  损失的体验近似，不宣称已经模拟跳球轨迹。

台呢实验来自斯诺克装置，因此只作为运动趋势与数量级的迁移依据，不宣称是对
中式台球台呢的独立材料测量。默认档位的停距和高力度曲线属于基于球台几何及
公开职业开球速度的体验标定。

## 碰撞后的速度

- 球球碰撞使用恢复系数 `0.97` 和摩擦系数 `0.10`。等质量球以 `100 cm/s`
  正碰静止球后，母球与目标球分别为 `1.5 cm/s` 和 `98.5 cm/s`，系统平动
  动能降低约 3%；斜撞的切向冲量会生成碰撞偏移（throw）与旋转。
- 库边恢复系数使用 `clamp(1 - 0.056 * incident_m/s, 0, 0.93)`，摩擦系数
  为 `0.14`，库鼻高度为 `1.4R`。因此低速反弹最多保留 93% 的法向速度，
  速度越高损失越明显，并会在平动与旋转间交换能量。

这些参数来自仓库中已经冻结、执行过公开参考数据验证的 Phase 3 碰撞配置；
桌面互动 profile 只复用参数，不改变证据回放所使用的冻结基线。

## 固定步进与追帧

交互循环以单调时钟累计真实时间，每累计 `1/120 s` 执行一次物理步进。每次
窗口回调最多追赶 12 步，避免长时间阻塞后无限补算。超过预算的时间必须丢弃并
输出累计诊断，不允许无声改变模拟时间。

累加器使用双精度。步进边界使用随固定步长缩放的浮点比较容差，确保 60、120
和 144 Hz 等常见显示节奏在十秒窗口内推进完全一致的模拟时间。

## 渲染插值

渲染状态由最近两个已完成物理 tick 生成：

```text
alpha = accumulator / fixed_step
rendered = interpolate(previous_physics, current_physics, alpha)
```

只插值球的位置、视觉旋转以及跟随母球的相机目标。进袋、犯规、玩家切换、碰撞
事件和游戏结束等离散状态始终采用当前物理状态。球的进袋拓扑发生变化时禁止跨
拓扑插值，避免球穿过袋沿或其他几何体。发生球球或球库碰撞的 tick 具有分段
轨迹，禁止用起止点之间的单一直线插值球的位置；该 tick 直接显示求解后的端点，
避免插值弦在视觉上穿过接触球或库边。

## 验证门槛

1. 时间正确性：60、120、144 Hz 下十秒均精确推进 1200 个 tick，正常刷新不得
   丢弃模拟时间。
2. 视觉流畅性：运动期间每个显示帧都产生新的插值位置，帧间位移保持有界；
   跟随相机使用同一插值母球位置。
3. 物理真实性：120 Hz 的自由滚动和库边碰撞必须收敛到 240 Hz 参考，低速球
   必须完全停止；公开参考数据和 Phase 3 release gate 必须继续通过。
4. 回归兼容性：单元测试、自动化协议、渲染截图、开球后视角拖动、最终停球和
   完整 E2E 测试全部通过。
