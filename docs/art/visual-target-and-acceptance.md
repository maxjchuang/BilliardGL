# 原创视觉目标与验收标准

日期：2026-07-27
方向名称：专注训练厅（Focused Practice Hall）
参考原则：学习真实材质、照明层级和台球可读性；不复制 Shooter's Pool 或其他竞品的资产、品牌、界面、配色组合和场馆布局

## 1. 视觉命题

BilliardGL 应呈现一个安静、可信、专注的中国式台球训练空间。玩家第一眼看到的是球、走位线索和袋口，第二眼才读到木材、金属和场馆。画面追求可训练的真实感，而非强烈电影滤镜或豪华会所装饰。

原创基调：

- 主色：低饱和青蓝台呢，区别于当前纯绿，也避免依赖任何竞品标志色。
- 结构：深胡桃木或烟熏木库边，枪灰金属角件，黑褐色袋口皮革。
- 灯光：暖中性矩形台灯，球台区域清晰，背景保持炭灰和低曝光。
- 造型：克制的矩形与圆角语言；不出现真实赛事品牌、球桌商标、赞助板或复制式装饰。
- 后期：中性曝光与轻微高光 roll-off；正常击球不使用景深、色差、镜头污渍和强 bloom。

## 2. 总体可读性门槛

- 1920×1080 Medium 质量下，所有常规镜头都能分辨母球、黑八和当前目标球组。
- 台灯是最高亮度来源，但灯罩和球体高光保留层次，不出现大片纯白截断。
- 球台主体平均亮度比背景高约 2–3 EV；背景仍保留墙地交界和近处轮廓。
- 画面静止时球不漂浮、不嵌入台呢；运动时高光不明显闪烁，编号不游移。
- 材质差异主要由反射、粗糙度和微表面建立，不把阴影与高光烘进 base color。
- 六个视觉基线场景必须使用同一颜色管理与曝光策略，禁止逐场景偷偷调材质。

## 3. 材质目标

数值范围是首轮标定窗口，不是强制艺术常量。最终值由同一灯光下的目标截图批准。

### 3.1 球

目标：致密、抛光、带清漆感的酚醛树脂，而不是自发光塑料。

- 物理直径严格为 `5.715 cm`；渲染网格中心与物理球心一致。
- base color 保留鲜明身份色，但亮色不超过显示映射可恢复范围；白区略暖且仍有层次。
- dielectric metallic=`0`；主体 roughness 建议 `0.08–0.18`；clearcoat 权重 `0.8–1.0`、roughness `0.03–0.10`，或用经批准的兼容近似。
- 台灯应在球面形成长方形/条形高光，随球旋转和镜头连续移动；高光不能像固定白贴纸。
- 编号圆与条纹边缘在球体特写中清晰，在战术俯视中仍能分组；接缝不得穿过主要编号区。
- 球体 normal 不添加肉眼可见的凹凸噪声；微划痕只允许在特写和掠射光下极轻出现。

验收：球体特写场景中，至少能同时读到台灯高光、环境暗部、球色和编号；球下阴影接触核落在球心投影附近，边缘柔和且不出现黑色圆盘。

### 3.2 台呢

目标：均匀、密实、具有方向性的精纺台呢，不是纯色平面、地毯或噪点材质。

- base color 目标为低饱和青蓝；批准时以线性/HDR 输出为准，不以单个十六进制值锁死。
- roughness 建议 `0.72–0.92`，metallic=`0`。
- 微表面 normal 表现细纤维方向，常规球员视角不应出现明显颗粒；球体特写或袋口特写可读到微弱绒向。
- 每米不应出现超过一次的明显纹理重复；不得有烘焙明暗、污渍照片或尺度不明的织物纹理。
- 方向性细节必须与球台长轴一致，UV1 可预留烘焙/AO，不得依赖运行时非等比缩放纠正比例。

验收：俯视场景台呢无大块 banding、摩尔纹和重复块；低位瞄准场景沿台面能看到柔和亮度渐变，但瞄准线仍清晰。

### 3.3 木材

目标：深胡桃木饰面与耐用透明漆层，纹理服务于台体结构。

- 木纹沿每根库边长轴排布，四边不能用同一方向硬贴；角部纹理接缝不可在常规镜头跳变。
- metallic=`0`；清漆表面 roughness 建议 `0.24–0.42`，局部变化控制在 ±0.08 内。
- base color 不包含摄影高光和强 AO；normal 只表达细导管与小尺度起伏。
- 木纹尺度按真实板材校准，禁止当前画面中宽大重复条带。

验收：电视斜俯视中，木边轮廓和纹理可辨但亮度低于球；沿边移动镜头时反射连续，不出现贴图闪变。

### 3.4 金属

目标：枪灰阳极/拉丝金属角件与接牙，低调但能与木材区分。

- metallic=`0.9–1.0`；roughness 建议 `0.18–0.38`。
- 拉丝方向应服从零件加工方向；金属不得用灰色漫反射代替。
- 边缘采用真实小倒角，让台灯形成稳定高光；不使用纯白轮廓线。

验收：袋口特写和球杆特写中，金属具备环境色反射，既非镜子也非灰塑料；无火花状 aliasing。

### 3.5 袋口

目标：从库边鼻口到皮革包边、暗色内壁、落袋空间形成连续深度。

- 角袋和中袋分别建模，不允许只缩放同一洞口。
- 材质至少拆为 `cushion_rubber / pocket_leather / pocket_inner`；金属角件若存在则独立。
- 皮革 metallic=`0`、roughness 建议 `0.48–0.72`，有细小压纹但不夸张。
- 内壁可以接近黑色，但 base color 不得为绝对 `0`；深度主要依靠几何、遮蔽和灯光。
- 库边鼻口和袋口可见边界必须与物理开放区对齐；允许装饰层超出，但不能误导可进球范围。

验收：袋口特写中能分辨至少三层深度，球进入时不穿过可见库边或悬在黑平面上；六个袋口均通过物理对齐叠加检查。

### 3.6 球杆

目标：可信的多材质比赛杆，接触点明确，运动时轮廓稳定。

- 新模型以皮头中心为原点，杆身沿本地 `+Z` 延伸；不再通过网格最小值猜测 tip offset。
- 最少拆分 `tip / ferrule / shaft / wrap_or_butt / joint`；可将不需要独立 draw 的部分合并为共享材质图集。
- 前节木材以浅色、低对比直纹表现；后把有薄漆层；皮头为哑光；接牙为金属。
- 尺寸由设计和物理输入共同批准；Phase 2 不用视觉杆长改变击球模型。

验收：低位瞄准时杆头、母球击点和瞄准轴共线；球杆不穿过母球或台边，近景材质至少能区分皮头、先角和前节。

## 4. 台灯与场馆

### 4.1 台灯

- 原创无品牌矩形灯具，长轴沿球台长轴；造型简洁、边缘有实际厚度。
- 色温目标 `4300–4800 K`，显色保持球色区分；不得用纯白无色光覆盖材质差异。
- 发光面应在球体上形成可识别的长方形反射；灯具几何本身不进入正常瞄准视野。
- 台面中心与四角曝光差在首轮目标中控制到约 ±15%；袋口可更暗但不能失去边界。
- 阴影软硬与灯具面积一致；球体 shadow acne、peter-panning 和双影均为阻断问题。

### 4.2 场馆

- 一座约 10×10×4 m 的比赛/训练兼用空间，只制作镜头可见区域。
- 台边至少预留约 1.8 m 的视觉操作空间；不得用家具制造不可能的出杆位置。
- 背景使用炭灰吸音墙、深色地面、少量原创长椅/置物架轮廓；首版无观众、屏幕广告和动态品牌牌。
- 背景材质使用模块化平铺和 trim sheet；远景不占用球与球台的高分辨率预算。
- 球桌是唯一主视觉焦点。环境亮点、反光地面、强对比海报不得与球号竞争。

验收：四类镜头无明显空盒感，墙地和灯具建立空间层次；隐藏全部远景装饰后仍可正常比赛，说明玩法没有依赖装饰资产。

## 5. 四类镜头标准

参数是可调初值，最终由六个基线场景冻结；所有距离以真实厘米语义记录。

| 镜头 | 目的 | 构图与建议参数 | 验收 |
| --- | --- | --- | --- |
| 球员击球视角 | 主要操作 | 相机位于母球后方，视高约台面上 18–35 cm，FOV 45–55°；杆、母球、目标球和目标袋形成单一视觉轴 | 默认无 HUD 时仍能理解击球方向；球杆不挡住目标球 |
| 低位精瞄视角 | 精细瞄准与击点 | 视高约台面上 8–16 cm，FOV 38–48°；母球占画面高度约 8–14%，目标点靠近中心安全区 | 母球轮廓、击点和目标球清晰；透视不夸张，镜头不穿台呢 |
| 战术俯视 | 走位规划 | 正俯视或极小倾角，完整可打台面保留 8–12% 安全边距；优先透视长焦或正交近似 | 16 个球和六袋均可见；HUD 不遮挡台角和关键球 |
| 电视斜俯视 | 观察、回放、展示 | 俯角约 30–45°，FOV 35–50°，沿球台对角线或长边构图；允许平滑跟随但不自动摇摆 | 球路不被库边遮挡；背景提供层次但台面仍占主要画幅 |

镜头切换采用缓动，但进入低位精瞄后必须完全稳定。正常击球镜头不使用景深；回放展示可在不影响球路判断时使用极轻景深。

## 6. 六个视觉场景的验收焦点

| 场景 | 主验收项 | 阻断问题 |
| --- | --- | --- |
| 开球 | 球号可读、三角区接触阴影、台面照度均匀 | 球相互穿插、颜色不可分、阴影变黑块 |
| 低位瞄准 | 球杆/击点共线、台呢微表面、目标袋可读 | 杆穿球、镜头穿台、瞄准线被材质吞没 |
| 球体特写 | clearcoat、编号 UV、台灯反射、接触核 | 固定高光、接缝穿编号、漂浮感 |
| 袋口特写 | 三层深度、皮革/内壁、鼻口物理对齐 | 黑平面洞、可见边界误导、穿模 |
| 战术俯视 | 全台信息、球组识别、纹理抗摩尔纹 | 台角被裁、球号闪烁、台呢重复明显 |
| 击球后观察 | 运动高光、阴影稳定、电视构图 | 高光闪烁、阴影拖尾、镜头丢失关键球 |

## 7. 评审方式

每次里程碑使用固定物理状态、固定镜头、1920×1080、Medium 质量和同一曝光生成截图；严禁用 DCC 离线渲染代替游戏内验收。

评审顺序：

1. 灰模检查比例、遮挡、袋口与物理对齐。
2. 中性材质检查灯光、曝光、阴影和镜头。
3. PBR 材质检查身份、尺度和反射。
4. 运动场景检查闪烁、UV、LOD 和跟随镜头。
5. 性能与截图回归同时通过后批准。
