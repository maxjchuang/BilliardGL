# Phase 2 首批资产 Backlog

日期：2026-07-27
目标：在 ModernRenderer 上交付“一张可信的中国式台球桌”，满足六个视觉场景与 1080p Medium 性能门

## 1. 排产原则

- 先冻结物理对齐灰模，再生产高模和纹理。
- 先完成球、台呢、袋口和库边这些所有镜头都可见的资产，再做场馆远景。
- 每个资产先过离线检查，再进游戏截图；不接受只在 DCC 渲染器里好看的交付。
- 所有内容原创或有明确可再发布授权；无法举证的 legacy 内容不得作为新资产输入。
- 图形开发未确认 clearcoat、glTF 扩展和材质实例策略前，不批量制作依赖该能力的纹理。

## 2. 依赖顺序

```text
物理尺寸清单 + glTF 单资产 spike
  -> 球台灰模与 alignment markers
    -> 核心材质样球 / 台呢平面
      -> 球台 LOD0 + 袋口近景
        -> 球 / 球杆 / 台灯
          -> 场馆模块与 LOD
            -> 六场景 polish + 性能收敛
```

## 3. P0：阻断竖切的资产

### ART-201 球台物理对齐灰模

交付：`bg_table_chinese8_training` 灰模 glTF、六袋 socket、库边鼻口基准、尺寸 manifest。

验收：

- 可打区域严格映射 `127 × 254 cm`，台高映射经物理负责人批准。
- 角袋、中袋分别建模；六袋 opening overlay 在容差内。
- 无未应用 scale；root 在地面中心；不依赖 X/Z 非等比运行时补偿。
- 从开球、低位、俯视和袋口镜头均无明显比例错误。

依赖：图形开发提供 glTF loader spike；物理负责人提供唯一尺寸来源。
估算：2–3 人日。

### ART-202 PBR 材质校准套件

交付：标准球体、1 m 台呢平面、木/金属/皮革样片、固定曝光预览场景及参数表。

验收：

- 每种材质的 base color、normal、ORM、clearcoat 路径符合生产规范。
- 同一台灯下能清晰区分树脂、台呢、清漆木、金属和皮革。
- 游戏内截图与目标范围一致，无 DCC 专有 shader。

依赖：ModernRenderer PBR 和 tone mapping spike。
估算：3–5 人日。

### ART-203 球台 LOD0 核心模型

交付：台呢、库边橡胶、木饰面、台体、金属角件、袋口皮革和袋内壁；独立材质槽和正确倒角。

验收：

- ≤80k 三角形、≤8 材质槽；预算集中在袋角、鼻口和镜头可见轮廓。
- 不从旧 `table.obj` 重拓扑或烘焙；尺寸源自 ART-201。
- 袋口特写能看到至少三层深度；球入袋无穿可见实体。
- 木纹与台呢方向正确，无明显重复和 UV 跳变。

依赖：ART-201、ART-202。
估算：8–12 人日。

### ART-204 台呢材质

交付：原创青蓝台呢 base color、normal、ORM，可平铺预览和参数实例。

验收：

- 1K–2K 平铺，roughness 与微表面处于目标范围。
- 俯视无摩尔纹和重复块；低位有柔和方向性，不干扰球路和瞄准线。
- 不含烘焙灯光、照片污渍或竞品采样颜色。

依赖：ART-202、ART-203 UV。
估算：2–4 人日。

### ART-205 球网格与原创身份图集

交付：共享球网格 LOD0/1/2、母球与 1–15 球原创编号/条纹图集、PBR 材质实例。

验收：

- 直径 `5.715 cm`，球心原点；LOD 轮廓无可见跳变。
- 编号/条纹旋转不镜像、不游移，接缝不穿主要编号区。
- 低位和球体特写具备连续台灯高光；战术俯视可辨球组。
- 16 球实例化，共享网格与材质资源；纹理驻留符合预算。

依赖：ART-202、图形开发确认球身份渲染策略。
估算：5–8 人日。

### ART-206 袋口与库边最终材质

交付：原创皮革、橡胶、内壁、金属角件、木饰面贴图和材质；角袋/中袋特写 polish。

验收：

- 所有材质符合目标 roughness/metallic 和纹理通道规范。
- 黑色内壁仍保留几何层次；不存在纯黑平面洞。
- 阴影下袋口边界可读，且不会暗到误导有效开口。

依赖：ART-203、ART-204。
估算：5–7 人日。

### ART-207 比赛球杆

交付：原创球杆 LOD0/1/2，皮头、先角、前节、后把/握把、接牙材质。

验收：

- tip 原点、`+Z` 朝向和尺寸符合规范，≤6k LOD0、≤5 材质槽。
- 低位瞄准时 tip 与母球击点视觉共线；无旧代码式 tip offset 猜测需求。
- 木、漆、皮头和金属在游戏灯光下可区分；细长 UV 没有大面积浪费。

依赖：图形开发与击球控制模型确定挂接约定。
估算：4–6 人日。

### ART-208 矩形台灯

交付：原创无品牌灯具 LOD0/1/2、金属/扩散板/emissive 材质、建议光源尺寸与位置 marker。

验收：

- 发光面在球体反射中形成稳定矩形高光；灯具不挡常用镜头。
- ≤12k LOD0、≤3 材质槽；无纯白大片 clipping。
- 灯光中心/四角均匀度在约 ±15% 目标内，最终由图形开发的 area-light 近似验证。

依赖：ART-202、图形开发 shadow/area-light 路径。
估算：3–5 人日。

## 4. P1：完成场馆与性能的资产

### ART-209 球台 LOD1/LOD2 与遮挡拆分

- LOD1 ≤40k、LOD2 ≤15k；包围盒、原点、material IDs 与 LOD0 一致。
- 袋口和球台外轮廓在电视/俯视距离不跳变。
- 可隐藏台底或镜头外细节，但不得隐藏影响球路判断的鼻口。

估算：3–5 人日。

### ART-210 场馆模块灰模

- 墙、地、天花、台灯吊装和最少背景轮廓；围绕球台保留约 1.8 m 操作空间。
- 四类镜头均无空盒感和遮挡；典型完整场景几何仍在预算内。
- 不制作观众、广告屏和品牌牌。

估算：3–5 人日。

### ART-211 场馆材质与 trim sheet

- 炭灰墙面、低反射地面、结构 trim 与少量木/金属背景模块。
- 1K–2K 可复用纹理；背景亮度比球台低 2–3 EV，无抢眼重复。
- 完整场馆 Medium 纹理驻留 ≤256 MiB。

估算：4–6 人日。

### ART-212 原创低优先装饰

- 最多一组长椅和一组置物架，使用 LOD；只有在电视镜头明显可见时制作。
- 不迁移旧 bench/wardrobe 网格或纹理。
- 可通过 manifest 完全关闭，不影响玩法和灯光。

估算：2–4 人日，可从 Phase 2 删减。

## 5. P0/P1 联合收尾

### ART-213 六场景游戏内材质与灯光收敛

- 针对开球、低位瞄准、球体特写、袋口特写、战术俯视、击球后观察逐项关闭阻断问题。
- 所有截图来自 rendered automation，同一曝光与颜色管理。
- 记录实际 tris、draw calls、纹理驻留和 GPU pass 时间。

估算：4–6 人日。

### ART-214 LOD、mip 与运动伪影检查

- 球滚动、镜头切换和击球后跟随无 LOD 抖动、编号 mip bleeding、normal 闪烁和阴影脱离。
- 1080p Medium P95 总帧时间满足 16.7 ms；若未满足，形成按资产和 pass 的可执行降本清单。

估算：2–4 人日，与图形开发联合。

### ART-215 授权与发布清单

- 每个 production asset 有作者、来源、许可、再发布权和 content hash。
- 发布 manifest 不包含任何 `replace_before_release` legacy 文件。
- 生成 legacy bridge 与 production 两份清单，支持安全回滚。

估算：1–2 人日，项目负责人签字。

## 7. 主要风险与应对

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 物理袋口形状与新视觉轮廓不一致 | 进球看似穿模或被挡 | ART-201 先冻结 overlay；每个袋口设 socket 和容差测试 |
| clearcoat/IBL 实现延迟 | 球材质无法批准 | ART-202 同时准备标准扩展和基础 PBR 近似，禁止两套纹理大规模分叉 |
| 图集策略过晚变化 | 球号与材质返工 | ART-205 前由图形开发冻结实例/贴花策略 |
| 旧资产授权不明 | 无法发布 | 从一开始原创重做，旧资产只留 legacy bridge |
| 远景消耗预算 | 核心球台降质 | ART-212 可裁剪；优先保留球、袋口和轮廓预算 |
| 截图变漂亮但运动闪烁 | 实际游戏体验不合格 | ART-214 强制动态回放验收，不以静帧替代 |
