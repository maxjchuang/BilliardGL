## 课程目标与判定

| 课程 | 教学约束 |
| --- | --- |
| 左塞一库 | 目标球进指定袋，白球恰好一库并停进目标圈 |
| 右塞一库 | 与左塞对应，白球恰好一库并停进目标圈 |
| 侧旋两库 | 目标球进指定袋，白球恰好两库并停进目标圈 |
| 角袋切球 | 指定目标球直接进指定角袋，白球不碰库并进入控制区 |
| 中袋切球 | 指定目标球直接进指定中袋，白球不碰库并进入控制区 |
| 两球连续走位 | 按显示顺序与指定袋口完成两球，白球不碰库，最后进入控制区 |
| 三球连续走位 | 按显示顺序与指定袋口完成三球，白球不碰库，最后进入控制区 |
| 正面开球控制 | 首先击中头球，使足够多目标球到达库边，白球不落袋并留在控制区 |
| 切角开球控制 | 从偏置位置切击头球，达到开球散球要求，白球不落袋并进入控制区 |

开球训练使用三颗目标球的紧凑教学球组，练习散球与控白，不是完整十五球实战开球，也不是“保证开球进球”；不显示虚构目标袋口。多球课中间杆没有额外停球圈要求，只在最后一杆检查控制区。

## 交互与显示

- 所有新版课程提供可读目标、推荐力度与击球点、实际球号及目标标记。
- 切球分别显示白球接近方向与目标球入袋方向，不把两段路径强行当作共线直线。
- 多球课根据实际进球进度切换提示；点击 Prepare shot 才应用下一杆推荐，不自动出杆或在停球时转动视角。
- Prepare shot 在观察、瞄准及镜头过渡状态下均应保持 Tab 切换后的对准。
- 多球课使用 Restart drill 重开完整序列，避免丢失前杆事实后错误计分；用完杆数仍未完成即结束尝试。
- 末杆结束后保持最后一杆提示，不跟随已入袋球的收纳坐标。
- 剩余九课同时检查整次尝试的白球落袋历史，不能利用落袋后重新摆球的最终状态误通过。

## 人工复测步骤

1. 退出旧游戏进程，用 `build-product-session/Billiards --product-mode` 重新启动。
2. 进入 Training，从左塞一库开始；查看目标球、袋口、目标圈，以及底部推荐力度和击球点。
3. Watch demo 仅用于看示范，不计本人通关。返回尝试后按推荐值出杆，等停稳查看 PASSED 或具体失败原因。
4. 单球课成功后用 Next drill 连续推进；多球课第一杆后点 Prepare shot，再自行出下一杆。Restart drill 会重开整套。
5. 遇到异常保留当前本地日志即可，无需录屏。自动通过记录不替代手感和教学易懂程度的人工确认。
